# GTK Piano

A simple piano app vibe coded in 1h because I needed one right now. Tested on Arch and Ubuntu Linux. Depends on `gtk3`.

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./piano.py

```
